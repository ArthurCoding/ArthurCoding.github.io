# Portfólio · Arthur Saraiva

Site pessoal publicado em **https://arthurcoding.github.io**.

Infraestrutura, redes e segurança da informação. HTML, CSS e JavaScript puros, sem dependências nem build.

## Como atualizar

Todo o conteúdo fica em `data.js`. Para mudar um texto ou adicionar um projeto, edite só esse arquivo e faça o commit. O GitHub Pages publica a nova versão em 1 a 2 minutos.

| Arquivo | Função |
|---|---|
| `index.html` | Estrutura da página |
| `styles.css` | Visual, temas claro/escuro e animações |
| `data.js` | Conteúdo: perfil, experiências, projetos, certificações |
| `main.js` | Monta a página a partir do `data.js` (carrosséis, abas, mapa de rede) |
